## Nota sobre conflito de datas

Há uma possível confusão entre **09/07**, **10/07** e **11/07**:

- O email do professor indica **quinta-feira, dia 09/07**, com aulas presenciais devido a avaliações.
- No grupo foi referido que **10/07 é sexta-feira**, logo a avaliação provavelmente não é dia 10.
- A imagem da estrutura do curso mostra **Avaliação 09/07**.
- A imagem também menciona PL aos sábados, incluindo **11/07**.

Conclusão provisória:

> Considerar **09/07 como data principal da avaliação presencial**.  
> Considerar **11/07 como possível aula PL/laboratório**, mas confirmar no calendário oficial.

## Estratégia para os guiões PL

Para cada guião, guardar:

| Campo | Exemplo |
|---|---|
| Objetivo do guião | O que o exercício tenta demonstrar |
| Comandos usados | `ip a`, `ping`, `nmap`, `iptables`, `ufw`, etc. |
| Resultado observado | Host ativo, porta aberta, porta filtered, tráfego bloqueado |
| Interpretação | O que o resultado significa em segurança |
| Erros comuns | Firewall ativa, IP errado, interface errada, VM sem rede |
| Frase para avaliação | Explicação curta para o professor |
