| Ação               | Nano                    |
| ------------------ | ----------------------- |
| Procurar           | `Ctrl + W`              |
| Cortar linha       | `Ctrl + K`              |
| Colar              | `Ctrl + U`              |
| Copiar linha/bloco | `Alt + 6`               |
| Marcar seleção     | `Ctrl + 6` ou `Alt + A` |
| Ir para linha      | `Ctrl + _`              |
